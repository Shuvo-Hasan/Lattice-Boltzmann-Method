This repository contains my personal notes, Python-converted code, and some projects on the Lattice Boltzmann Method.

# Acknowledgement

The code and projects are based on the MATLAB code provided in the book

Mohamad, A. A. (2019). Lattice Boltzmann Method: Fundamentals and Engineering Applications with Computer Codes (2nd ed.). Springer London. https://doi.org/10.1007/978-1-4471-7423-3

The implementations in this repository have been modified, extended, and documented for educational and research purposes. Any remaining errors or modifications are entirely my own.
